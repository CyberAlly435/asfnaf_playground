# Another Seven's FNaF Fangame: Playground
ASFNAF deve ter um carregador de mods!

## Sobre o Repositório
O repositório faz parte de um programa de construção de modificações e testes a fim de construir um "Modloader".

## Preparativos para Inicialização
Quando iniciar o arquivo em .x86_64 pela primeira vez, talvez receba um erro logo no início.  
  
Isso acontece por que o AppManager.cs não é incluído dentro destas builds. Então, para resolver provisóriamente este problema, é necessário criar subpastas para os Mods.

```bash
mkdir -p ~/.config/Angelo/MangleFiles/Mods
```
