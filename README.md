# Another Seven's FNaF Fangame: Playground
ASFNAF deve ter um carregador de mods!

## Sobre o Repositório
O repositório faz parte de um programa de construção de modificações e testes a fim de construir um "Modloader".

## Preparativos para Inicialização
Quando iniciar o arquivo em .x86_64 pela primeira vez, talvez receba um erro logo no início.  
Isso acontece por que o AppManager.cs não é incluído dentro destas builds. Então, para resolver provisóriamente este problema, criei um arquivo .sh para um processo mais automatizado na qual você pode usar.

Dá permisão para que o arquivo se torne um executável.
```bash
chmod +x ./init.sh
```

Inicia o arquivo automático.
```bash
./init.sh
```  

Você também pode usar os comandos aqui embaixo caso não queira executar o arquivo
